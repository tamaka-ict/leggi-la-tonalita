LEGGI LA TONALITÀ 2.1 — AGGIORNAMENTO DEL TUO GITHUB

Repository: https://github.com/tamaka-ict/leggi-la-tonalita
Sito pubblico: https://tamaka-ict.github.io/leggi-la-tonalita/

1. Estrai il file ZIP sul computer.
2. Accedi al repository GitHub e vai sul ramo main.
3. Se vuoi, fai un backup con Code > Download ZIP.
4. Seleziona Add file > Upload files.
5. Carica i file estratti nella radice del repository (in particolare index.html e sw.js).
6. Conferma Commit changes direttamente su main.
7. Attendi la pubblicazione, quindi apri il sito e cerca 'Versione 2.1' in alto.
8. Apri Impara, verifica le 15 note, premi Prova il suono di una nota e Ascolta.
9. Durante la riproduzione cambia i BPM e verifica che la velocità cambi.

Non creare un nuovo repository e non modificare Settings > Pages.
Il collegamento pubblico rimane lo stesso.

I vecchi file app.js e scale.js non sono più necessari: il nuovo index.html
incorpora tutta la logica. Possono restare nella cartella di GitHub senza
provocare problemi; eventualmente puoi eliminarli in seguito.

Se compare ancora la versione 2.0, apri:
https://tamaka-ict.github.io/leggi-la-tonalita/?v=21
oppure chiudi e riapri il browser con connessione a Internet.
Evita di cancellare i dati del sito se vuoi conservare le statistiche.

In caso di mancanza di audio, prova il pulsante 'Prova il suono di una nota'
e verifica il volume multimediale del telefono.
