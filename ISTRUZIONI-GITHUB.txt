LEGGI LA TONALITÀ — AGGIORNAMENTO v2.2

1. Apri https://github.com/tamaka-ict/leggi-la-tonalita e accedi.
2. Vai sul ramo main e scegli Add file > Upload files.
3. Decomprimi il pacchetto ZIP sul tuo PC. Trascina nel sito GitHub i SEI FILE estratti (non lo ZIP e non la cartella).
4. Sostituisci i file con nomi identici. Conferma Commit changes.
5. Attendi che GitHub Pages completi la pubblicazione.
6. Apri https://tamaka-ict.github.io/leggi-la-tonalita/?v=22 e controlla che sia indicata Versione 2.2.
7. Vai in Impara > Visualizzazione durante l'ascolto > Schermata fissa per 5 note. Premi Ascolta.

Atteso: il pentagramma cambia inquadratura soltanto dopo 5 note (alla sesta e all'undicesima); le note continuano a illuminarsi una alla volta. La barra di avanzamento continua a muoversi.

Il link non cambia. Non è necessario modificare Settings > Pages.

NOTA: i file app.js e scale.js eventualmente rimasti dalla versione 2.0 sono inutilizzati, ma possono restare nel repository.
