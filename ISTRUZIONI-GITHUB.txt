LEGGI LA TONALITÀ — VERSIONE 2.0
================================

SE HAI GIÀ PUBBLICATO LA VERSIONE PRECEDENTE:

1. Accedi a github.com e apri il repository leggi-la-tonalita.
2. Per prudenza, puoi scaricare un backup: Code > Download ZIP.
3. Estrai sul computer lo ZIP della nuova versione.
4. Nel repository seleziona Add file > Upload files.
5. Trascina TUTTI i file CONTENUTI nella cartella estratta (non lo ZIP).
   Sostituisci quelli già presenti: index.html, app.js, sw.js, README.md,
   ISTRUZIONI-GITHUB.txt, manifest.webmanifest e icon.svg.
   Aggiungi il nuovo file scale.js.
6. Conferma il commit sul ramo main con il messaggio:
   Aggiorna alla versione 2 con scale sonore sincronizzate
7. GitHub Pages continuerà a usare lo STESSO link condiviso prima.
8. Se vedi la vecchia app, attendi la pubblicazione e ricarica il sito.
   Se usi l'icona installata sul telefono, chiudi e riapri l'app.

SE NON HAI ANCORA PUBBLICATO L'APP:

1. Registrati a https://github.com/signup
2. Crea un nuovo repository pubblico leggi-la-tonalita.
3. Estrai lo ZIP e carica i file interni con Add file > Upload files.
4. Settings > Pages > Source: Deploy from a branch > main > /(root) > Save.
5. Visita https://TUOUSERNAME.github.io/leggi-la-tonalita/

NOVITÀ:
- Scala maggiore e minore naturale, armonica e melodica.
- Ascolto con audio generato direttamente dal browser, anche offline.
- Cursore arancione sincronizzato con note e avanzamento orizzontale.
- Velocità regolabile, pausa e note ascoltabili singolarmente.
- Stesso quiz e punteggi della versione precedente.

CONTROLLI RAPIDI:
- Su Impara prova Do maggiore e premi Ascolta.
- Per sentire l'audio, premi il pulsante (autoplay non consentito).
- Su smartphone il pentagramma scorre seguendo la nota ascoltata.

Nella cartella README.md trovi le istruzioni dettagliate.
