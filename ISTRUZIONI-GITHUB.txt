LEGGI LA TONALITA' 3.0 - AGGIORNAMENTO GITHUB

1. Vai su https://github.com/tamaka-ict/leggi-la-tonalita
2. Fai eventualmente un backup con Code > Download ZIP.
3. Estrai il nuovo ZIP sul computer.
4. Con il repository su main: Add file > Upload files.
5. Carica nella radice TUTTI E SEI i file estratti (non caricare lo ZIP).
6. Premi Commit changes (direttamente su main).
7. Lascia invariato Settings > Pages.
8. Dopo la pubblicazione apri:
   https://tamaka-ict.github.io/leggi-la-tonalita/?v=30
9. Verifica la dicitura Versione 3.0 e la sezione Percorso.

La famiglia continua a usare il vecchio link pubblico.
Il percorso si sblocca con 5 risposte corrette su 6 per livello.
Progressi salvati separatamente nel browser di ogni familiare.
I vecchi app.js e scale.js non vengono piu' utilizzati e possono rimanere.
Per problemi di cache: ricarica il sito con ?v=30; non cancellare i dati
salvati sul dispositivo se vuoi preservare i progressi.
