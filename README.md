# Leggi la tonalità

App web gratuita per imparare e allenarsi a riconoscere le armature di chiave. Utilizzabile da telefono e PC; non richiede servizi esterni né account per gli utenti.

## Funzioni
- Chiave di Sol in prima e seconda linea, Fa in terza e quarta linea, Do dalla prima alla quinta linea.
- 15 armature (0–7 diesis e 1–7 bemolli), maggiori e relative minori.
- Tre livelli, risultati immediati, spiegazioni, punteggi e impostazioni salvate sul dispositivo.
- Installabile dal browser come web app; funzionamento offline dopo il primo accesso online (nei browser compatibili).

## Pubblicazione GitHub Pages
1. Crea un repository GitHub pubblico chiamato `leggi-la-tonalita`.
2. Carica **i file di questa cartella**, non lo ZIP e non la cartella contenitore. `index.html` deve apparire direttamente nella root del repository.
3. Vai in Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder: `/(root)` → Save.
4. Apri `https://TUO_USERNAME.github.io/leggi-la-tonalita/` sostituendo TUO_USERNAME con il tuo nome utente.

Non è necessario installare Git o GitHub Desktop. Il repository è pubblico: non inserire dati privati o credenziali.

## Nota musicale
L'armatura individua una coppia maggiore/minore relativa, non la tonalità effettiva di un brano: per distinguerla serve anche osservare melodia e armonia. I glifi delle chiavi sono disegnati direttamente in SVG per maggiore portabilità.
